# CAM2COOK for iOS

Native SwiftUI iOS client prototype for CAM2COOK.

## Open in Xcode
1. Open `app/iOS/Cam2Cook.xcodeproj` in Xcode 15 or newer.
2. Select the `Cam2Cook` scheme and an iPhone simulator running iOS 17+.
3. Build and run.

## Included
- Native dark-mode UI with iOS tab navigation.
- Home dashboard, inventory metrics, freshness reminders and recipe inspiration.
- Inventory search and filters, add item form, and mark-consumed action.
- Photo picker scan flow with a clear demo-mode notice.
- Sample recipe cards and profile/preferences screen.
- GitHub Actions builds a Simulator artifact and a device-targeted unsigned IPA.

## Download a build
Open **Actions → Build Cam2Cook iOS app → select the latest successful run → Artifacts**.

- `Cam2Cook-iOS-Simulator-<run>`: for the iOS Simulator only.
- `Cam2Cook-iOS-Unsigned-IPA-<run>`: unsigned iPhone-device build for sideloading.

### Install the unsigned IPA from Windows (free signing)
The IPA generated by GitHub Actions is **unsigned**. It is not a directly installable OTA package and tapping it in Safari will not install it. Without a paid Apple Developer membership, use a sideloading tool such as [Sideloadly](https://sideloadly.io/) or [AltStore](https://altstore.io/) on Windows to sign it with your free Apple Account and install it on your connected iPhone.

1. Trigger or wait for a successful workflow run on the `iOS-app` branch.
2. Download and extract the `Cam2Cook-iOS-Unsigned-IPA-<run>` artifact from that run's **Artifacts** section.
3. Install Sideloadly or AltStore using its official instructions, connect your iPhone, and follow its steps to sideload the downloaded `.ipa`.
4. Follow any trust / Developer Mode prompts shown by your iPhone or the sideloading tool.

Free Apple Account signing generally expires after 7 days, so the app must be refreshed/reinstalled periodically. Keep your Apple Account credentials private and enter them only into the official tool you choose. A direct, public over-the-air installation link or TestFlight distribution requires Apple's supported signing/distribution setup and is not provided by this unsigned artifact.

## Integration status
Inventory and recipes currently use in-memory/sample data. AI food recognition, backend authentication/sync, push notifications and real recipe APIs are not yet integrated. Freshness values are estimates, not food-safety guarantees.
